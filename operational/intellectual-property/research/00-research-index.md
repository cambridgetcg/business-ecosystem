## Critical Model Gaps Summary

### Phase 1 Gaps: Core IP Mechanics

#### Patent Entity Missing
- Family ID and parent-child relationships
- Continuation type (continuation/divisional/CIP)
- PCT application tracking
- Maintenance fee payment records
- Entity size (large/small/micro)
- SEP declarations and FRAND commitments
- Federal funding source (for march-in rights)

#### Trademark Entity Missing
- Registration type (national vs Madrid)
- Madrid IR number and dependency tracking
- Section 8/9 declaration records
- Use status per Nice class
- Specimen storage/tracking

#### Copyright Entity Missing
- Duration calculation inputs (author deaths, reveal dates)
- Calculated expiration date
- Fair use assessment framework

#### License Entity Missing
- FRAND license indicators
- Rate-setting method and jurisdiction
- Government use tracking (§1498)

#### Entirely Missing Entity
- **Trade Secret** - needs complete implementation

2. **Deep Understanding**: Read all current domain entities to identify gaps

## Aha Moments Captured (Phase 3)

These insights emerged during the integration of Phases 1-2 and drove Phase 3 research:

1. **The Compliance Paradox** - IP rights that took years to build can be destroyed by a single missed deadline. Led to: Doc 17 (Deadline Failures)

2. **The Rolls Royce Lesson** - $700M+ spent and couldn't use the name. M&A due diligence failures follow patterns. Led to: Doc 18 (Due Diligence Disasters)

3. **Article of Manufacture Uncertainty** - Apple won at the Supreme Court but the uncertainty may have hurt them. Led to: Doc 19 (Design Patent Damages)

4. **Alice Creates Schrödinger's Patents** - 88.6% PTAB affirmance means once challenged, survival is unlikely. Led to: Doc 20 (Alice Survival Rates)

5. **Open Source is Not Free** - €800K damages in Entr'ouvert shows copyleft has teeth. Led to: Doc 21 (Copyleft Enforcement)

6. **Central Attack Game Theory** - 7,000 IRs cancelled in one year. The vulnerability is systemic. Led to: Doc 22 (Madrid Central Attack)
