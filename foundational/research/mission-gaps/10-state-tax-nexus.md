## Research Findings

### Post-Wayfair Nexus Landscape (2025)

From [TaxCloud](https://taxcloud.com/blog/sales-tax-nexus-by-state-2025/) and [Numeral](https://www.numeral.com/blog/economic-nexus):

```
CURRENT STATE OF NEXUS (2025):

All 45 Sales Tax States:
├─ Have adopted economic nexus rules post-Wayfair (2018)
├─ Remote sellers must collect/remit based on thresholds
└─ Physical presence no longer required

Common Thresholds:
├─ Revenue threshold: $100,000 in annual sales (most states)
├─ Transaction threshold: 200 transactions (declining trend)
└─ Some states: Revenue OR transactions (whichever first)

2025 Trend: Transaction Threshold Elimination
├─ 15+ states have eliminated 200-transaction threshold
├─ Focus shifting to revenue-only thresholds
├─ Reduces compliance burden for small sellers
└─ More states expected to follow
```

### Two Types of Nexus

From [Galvix](https://www.galvix.com/sales-tax-nexus/) and [KLR](https://kahnlitwin.com/blogs/tax-blog/what-is-nexus-and-how-does-it-impact-sales-tax-compliance-in-2025):

```
PHYSICAL NEXUS vs ECONOMIC NEXUS:

PHYSICAL NEXUS (Traditional):
├─ Creates nexus from Day 1 of activity
├─ No threshold - any physical presence triggers
└─ Supersedes economic nexus thresholds

Physical Nexus Triggers:
├─ Office, warehouse, or facility
├─ Employees (including remote workers)
├─ Inventory stored in state
├─ Salespeople traveling to state
├─ Trade show attendance (some states)
├─ Contractors performing services
├─ Fulfillment center (even third-party)
└─ Any owned/leased tangible property

ECONOMIC NEXUS (Post-Wayfair):
├─ Creates nexus when threshold exceeded
├─ No physical presence required
├─ Threshold usually measured over prior or current 12 months
└─ Must register and collect once threshold crossed

Economic Nexus Triggers:
├─ Revenue threshold crossed ($100K typical)
├─ Transaction count threshold crossed (200 typical, declining)
└─ Usually: Revenue OR transactions, whichever comes first

IMPORTANT:
┌─────────────────────────────────────────────────────────────────────────────┐
│  If you have PHYSICAL nexus, the economic thresholds DO NOT APPLY.         │
│  Physical nexus = immediate sales tax obligation from first sale.           │
└─────────────────────────────────────────────────────────────────────────────┘
```

### State-by-State Thresholds (2025)

From [Avalara](https://www.avalara.com/blog/en/north-america/2025/06/states-eliminating-economic-nexus-transaction-thresholds.html) and [TaxCloud](https://taxcloud.com/blog/ecommerce-sales-tax-nexus-by-state-what-you-need-to-know/):

```
CURRENT ECONOMIC NEXUS THRESHOLDS (Selected States):

$100,000 Revenue ONLY (No Transaction Threshold):
├─ California, Texas, Florida, New York, Illinois
├─ Pennsylvania, Ohio, Georgia, North Carolina
├─ Virginia, Michigan, New Jersey, Arizona
└─ (Most major states now revenue-only)

$100,000 Revenue OR 200 Transactions:
├─ Alabama, Arkansas, Connecticut
├─ Idaho, Indiana, Iowa
├─ Kansas, Kentucky, Maine, Maryland
├─ Minnesota, Nebraska, Nevada
├─ (List shrinking as states remove transaction thresholds)

Lower Thresholds:
├─ Kansas: $100,000 (no transaction threshold as of 7/1/2025)
├─ Missouri: $100,000 (effective 1/1/2023)
└─ New York: $500,000 AND 100 transactions (both required)

Special Cases:
├─ Colorado: Home Rule cities have separate thresholds
├─ Louisiana: Single state registration, but parish-level rates
└─ Alaska: No state sales tax, but local jurisdictions may tax
```

### Expanding Beyond Sales Tax

From [CPA Journal](https://www.cpajournal.com/2025/09/30/how-wayfairs-economic-nexus-has-redefined-business-tax-obligations-2/):

```
INCOME TAX NEXUS EXPANSION:

States Using Economic Nexus for Income Tax:
├─ California: Factor-presence threshold
├─ Massachusetts: $500K sales threshold
├─ New York: Bright-line economic presence
├─ Connecticut, Hawaii, Oregon, others
└─ Trend: Increasing number of states

Income Tax Nexus Factors:
├─ Payroll in state
├─ Property in state
├─ Sales to state customers
├─ Digital presence (websites, apps)
└─ Affiliates operating in state

P.L. 86-272 Protection (Federal):
├─ Protects solicitation of tangible goods
├─ Does NOT protect:
│   ├─ Services
│   ├─ Digital products
│   ├─ Licensing
│   └─ Certain internet activities
└─ States increasingly interpreting narrowly
```

### Nexus Determination Procedure

```
SYSTEMATIC NEXUS ASSESSMENT:

Step 1: IDENTIFY ALL ACTIVITIES BY STATE
├─ List all states with any connection
├─ For each state, document:
│   ├─ Revenue from customers in state
│   ├─ Transaction count to state
│   ├─ Employees located in state (including remote)
│   ├─ Property or inventory in state
│   ├─ Travel to state (sales, trade shows)
│   └─ Third-party fulfillment in state
└─ Update at least quarterly

Step 2: CLASSIFY NEXUS TYPE
┌─────────────────────────────────────────────────────────────────────────────┐
│  FOR EACH STATE:                                                           │
│                                                                             │
│  IF physical presence exists:                                               │
│  └─ PHYSICAL NEXUS → Immediate registration required                       │
│                                                                             │
│  ELSE IF economic threshold exceeded:                                       │
│  └─ ECONOMIC NEXUS → Registration required                                 │
│                                                                             │
│  ELSE IF approaching threshold (80%+):                                      │
│  └─ MONITOR CLOSELY → Prepare for registration                             │
│                                                                             │
│  ELSE:                                                                      │
│  └─ NO NEXUS → Continue monitoring                                         │
└─────────────────────────────────────────────────────────────────────────────┘

Step 3: DETERMINE REGISTRATION REQUIREMENTS
├─ Identify correct state agency (usually Dept of Revenue)
├─ Determine if state participates in SST (Streamlined Sales Tax)
├─ Gather required information for registration
├─ Identify local jurisdiction requirements (if applicable)
└─ Set up tax calculation for state's rates

Step 4: ESTABLISH ONGOING COMPLIANCE
├─ Determine filing frequency (monthly, quarterly, annual)
├─ Set up return reminders and calendars
├─ Configure tax collection at correct rates
├─ Implement proper exemption certificate management
└─ Plan for audits and record retention
```

### Threshold Monitoring System

```
MONITORING FRAMEWORK:

Real-Time Tracking:
├─ Track rolling 12-month revenue by ship-to state
├─ Track rolling 12-month transaction count by state
├─ Calculate percentage of threshold reached
└─ Alert when approaching threshold (e.g., 80%)

Reporting Dashboard:
┌─────────────────────────────────────────────────────────────────────────────┐
│  State    │ Threshold │ Current Revenue │ % of Threshold │ Status          │
│  ─────────┼───────────┼─────────────────┼────────────────┼─────────────────│
│  CA       │ $100,000  │ $85,000         │ 85%            │ ⚠️ Approaching  │
│  TX       │ $100,000  │ $125,000        │ 125%           │ ✓ Registered    │
│  FL       │ $100,000  │ $45,000         │ 45%            │ Monitoring      │
│  NY       │ $500,000  │ $250,000        │ 50%            │ Monitoring      │
└─────────────────────────────────────────────────────────────────────────────┘

Alert Thresholds:
├─ 50%: Add to watch list
├─ 75%: Begin registration preparation
├─ 90%: Initiate registration
└─ 100%: Must be registered and collecting

Historical Analysis:
├─ Compare YoY growth by state
├─ Project when thresholds likely crossed
├─ Identify seasonal patterns
└─ Plan ahead for registration timing
```

### Registration Procedures

```
STATE REGISTRATION WORKFLOW:

Pre-Registration:
├─ Confirm nexus exists (physical or economic)
├─ Determine effective date of nexus
├─ Gather required documentation:
│   ├─ Federal EIN
│   ├─ State of incorporation details
│   ├─ Business structure information
│   ├─ Principal officer information
│   ├─ NAICS codes
│   └─ Estimated monthly/annual liability

Registration Options:

1. STREAMLINED SALES TAX (SST)
   ├─ 24 member states
   ├─ Single registration for all SST states
   ├─ Free registration and service
   ├─ Simplified compliance
   └─ Apply at: sstregister.org

2. INDIVIDUAL STATE REGISTRATION
   ├─ Non-SST states require individual registration
   ├─ Major non-SST states: CA, TX, FL, NY, IL
   ├─ Each has own registration portal
   └─ Some allow registration of multiple state business activities

3. REGISTERED AGENT SERVICES
   ├─ Third-party handles registrations
   ├─ Maintains registered agent in each state
   ├─ Useful for companies with many state registrations
   └─ Cost: $50-200 per state annually

Post-Registration:
├─ Obtain certificate of registration
├─ Configure tax collection at correct rates
├─ Set up filing calendar and reminders
├─ Understand penalty/interest for late filing
└─ Implement exemption certificate collection
```

### Ongoing Compliance Requirements

```
PER-STATE COMPLIANCE:

Filing Frequency (Varies by State and Volume):
├─ Annual: Low volume (<$100K liability typically)
├─ Quarterly: Medium volume
├─ Monthly: High volume (>$1,000-$4,000/month liability)
└─ Semi-monthly: Very high volume (some states)

Return Due Dates:
├─ Most states: 20th of following month
├─ Some states: End of following month
├─ Quarterly: End of month following quarter
└─ Check each state's specific requirements

Common Requirements:
├─ File returns even if no tax due ($0 returns)
├─ Collect and retain exemption certificates
├─ Apply correct tax rates (state, county, city, district)
├─ Handle different taxability rules by state
└─ Maintain records for audit period (3-7 years)

Rate Management:
├─ States have different rates (0% to 7%+)
├─ Local jurisdictions add additional rates
├─ Over 11,000 taxing jurisdictions in US
├─ Rates change frequently (monthly updates)
└─ Use automated tax calculation service
```

### Remote Employee Nexus

From [TaxCloud](https://taxcloud.com/blog/sales-tax-nexus-by-state-2025/):

```
REMOTE WORKER CONSIDERATIONS:

Physical Nexus from Remote Workers:
├─ Most states: Any employee creates physical nexus
├─ No revenue threshold applies
├─ Nexus exists from day employee starts
└─ Applies even to 1099 contractors in some states

Income Tax Implications:
├─ Employer may have income tax filing obligation
├─ Employee payroll withholding required
├─ May need to register with state employment agency
└─ Corporate income tax apportionment affected

Best Practices:
├─ Track all employee/contractor work locations
├─ Assess nexus implications before hiring
├─ Consider states before allowing remote work
├─ Include nexus clause in remote work policies
└─ Review annually as laws change
```
