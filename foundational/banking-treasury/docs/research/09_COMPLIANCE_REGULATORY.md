# Compliance & Regulatory Framework

## Overview

Global treasury operations require navigating complex, multi-jurisdictional AML/KYC requirements. Regulatory enforcement is intensifying, with significant penalties for non-compliance. Technology (RegTech) is essential for managing compliance at scale.

---

## Regulatory Landscape

### FATF (Financial Action Task Force)

**Role**: Sets global AML/CFT standards adopted by 200+ jurisdictions

| 2025 Update | Details |
|-------------|---------|
| **June 2025 Guidance** | New risk-based approach requirements |
| **Grey List Additions** | British Virgin Islands, Bolivia added |
| **Grey List Removals** | Croatia, Mali, Tanzania removed |
| **Virtual Assets** | 75%+ jurisdictions only partially compliant |
| **Travel Rule** | Enforced in 99+ countries |

**Key Requirements**:
- Enhanced National Risk Assessments (NRA)
- Transparency in beneficial ownership
- Risk-based approach to AML/CFT/CPF

**Source**: [FATF 2025 Guidance](https://www.finreg-e.com/fatfs-2025-guidance-smarter-aml-cft-compliance/)

## Perpetual KYC (pKYC)

### Concept

Traditional KYC is periodic (annual/bi-annual reviews). pKYC is continuous monitoring with event-triggered reviews.

| Aspect | Traditional KYC | pKYC |
|--------|----------------|------|
| **Frequency** | Periodic | Continuous |
| **Triggers** | Time-based | Event-based |
| **Data** | Point-in-time snapshot | Real-time updates |
| **Effort** | High manual reviews | Automated with exceptions |
| **Risk Detection** | Delayed | Near real-time |

### pKYC Triggers

- Change in beneficial ownership
- Spike in cross-border transactions
- Adverse media alerts
- Change in risk profile indicators
- Regulatory list additions

**Source**: [AML Regulation Updates 2025](https://adata.pro/blog/aml-regulation-updates-key-changes-and-impacts-on-global-financial-systems/)

### Key Principles

1. **Global Policy, Local Implementation**: Central standards adapted to local requirements
2. **Risk-Based Approach**: Resources allocated by risk level
3. **Technology-First**: Automation for scale and consistency
4. **Continuous Monitoring**: pKYC over periodic reviews
5. **Integrated Data**: Single customer view across jurisdictions

## Implementation Recommendations

### Phase 1: Foundation (0-3 months)

1. **Policy Framework**
   - Establish global AML policy
   - Define risk appetite
   - Create compliance governance structure

2. **Technology Selection**
   - Select RegTech platform(s)
   - Implement sanctions screening
   - Deploy identity verification

### Phase 2: Enhancement (3-6 months)

3. **Transaction Monitoring**
   - Implement AI-powered monitoring
   - Configure risk rules
   - Establish alert management

4. **Integration**
   - Connect to banking-treasury systems
   - Implement real-time screening
   - Enable API-based verification

### Phase 3: Optimization (6-12 months)

5. **pKYC Implementation**
   - Deploy continuous monitoring
   - Configure event triggers
   - Automate low-risk reviews

6. **Advanced Analytics**
   - Implement ML-based detection
   - Deploy network analysis
   - Enable predictive risk scoring

## Risk-Based Approach Matrix

| Risk Level | CDD Level | Monitoring | Review Frequency |
|------------|-----------|------------|------------------|
| **Low** | Simplified | Standard rules | Annual |
| **Medium** | Standard | Enhanced rules | Semi-annual |
| **High** | Enhanced | Real-time + ML | Quarterly |
| **Prohibited** | Decline | N/A | N/A |

### High-Risk Indicators

- Jurisdictions on FATF grey/black lists
- PEPs and their associates
- High cash-intensive businesses
- Complex ownership structures
- Adverse media
- Sanctions proximity
