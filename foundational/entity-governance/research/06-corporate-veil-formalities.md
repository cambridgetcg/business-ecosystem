# Corporate Veil and Formality Requirements

## Knowledge Gap Identified

Our model tracks meeting minutes and resolutions but doesn't capture the full scope of formalities required to maintain the corporate veil. Proper formalities are evidentiary foundations for liability protection - without them, owners risk personal liability (veil piercing).

## Key Findings

### What the Corporate Veil Actually Protects

```
                         WITHOUT CORPORATE VEIL
                    (Sole Proprietor / General Partner)

    Business Assets ──────────────► OWNER'S PERSONAL ASSETS
         │                                    │
    Business Debt ───────────────────────────┘

                         WITH CORPORATE VEIL
                    (Corporation / LLC - Properly Maintained)

    Business Assets ──────────────► Business Debt
         │                                │
         X─────────SHIELD─────────────────X
         │                                │
    Personal Assets               Personal is PROTECTED
```

### The Two Prongs of Veil Piercing

Courts universally require BOTH:

1. **Unity of Interest**: The entity and owner are not truly separate
   - Commingling of funds
   - Failure to observe formalities
   - Undercapitalization
   - Entity used as mere instrumentality/alter ego

2. **Inequitable Result**: If the court doesn't pierce, injustice results
   - Fraud or wrongdoing
   - Creditor left without remedy
   - Entity used to evade obligations

### Factors Courts Examine

| Factor | Weight | What Courts Look For |
|--------|--------|---------------------|
| **Commingling** | Very High | Personal and business funds mixed |
| **Undercapitalization** | High | Insufficient capital for business risks |
| **Failure to observe formalities** | High | No minutes, no meetings, no resolutions |
| **Alter ego** | Very High | Owner treats entity as extension of self |
| **Domination** | Medium | Single person controls everything |
| **Fraud/Injustice** | Required | Must show inequitable result |


### Intercompany Transaction Documentation

```
TYPES OF INTERCOMPANY TRANSACTIONS
──────────────────────────────────

┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐
│ SERVICES        │  │ GOODS/PRODUCTS  │  │ FINANCIAL       │
│ ─────────       │  │ ──────────────  │  │ ─────────       │
│ - Management    │  │ - Inventory     │  │ - Loans         │
│   fees          │  │   transfers     │  │ - Guarantees    │
│ - Shared        │  │ - IP licensing  │  │ - Capital       │
│   services      │  │ - Equipment     │  │   contributions │
│ - IT support    │  │   sales/leases  │  │ - Distributions │
│ - Accounting    │  │ - Raw materials │  │ - Cash sweeps   │
└─────────────────┘  └─────────────────┘  └─────────────────┘

DOCUMENTATION REQUIREMENTS:

1. WRITTEN AGREEMENT
   - Formal contract between entities
   - Signed by authorized officers of EACH entity
   - Terms clearly specified (price, payment, duration)
   - Board/member approval documented

2. FAIR MARKET VALUE
   - Pricing justified by market comparables
   - Transfer pricing study for significant transactions
   - Documentation of pricing methodology

3. ECONOMIC SUBSTANCE
   - Transaction has genuine business purpose
   - Services actually provided
   - Payment actually made (not just booked)

4. SEPARATE APPROVAL PROCESS
   - Each entity's board independently approves
   - No single person approving for both sides
   - Conflict of interest disclosed and managed
```

### Intercompany Loans - Special Requirements

Loans between related entities require extra formality to avoid recharacterization as equity:

```
REQUIRED ELEMENTS:
✓ Written promissory note
✓ Fixed maturity date (not demand note if possible)
✓ Stated interest rate (at least AFR minimum)
✓ Regular principal/interest payments actually made
✓ Security/collateral if appropriate
✓ Board approval of both borrower and lender
✓ Borrower must have ability to repay
✓ Enforcement provisions (default remedies)

RED FLAGS (Looks like equity, not debt):
✗ No maturity date
✗ No interest or below-market rate
✗ No payments ever made
✗ Debt exceeds borrower's ability to repay
✗ Loans increase as losses increase
✗ No written documentation
```

### Parent-Subsidiary Veil Piercing Risk

```
RISK FACTORS FOR PARENT LIABILITY
─────────────────────────────────

HIGH RISK: Subsidiary Treated as Department
  ✗ Shared bank accounts or cash pooling without agreements
  ✗ Parent pays subsidiary's bills directly
  ✗ Subsidiary has no independent decision-making
  ✗ Overlapping directors/officers with no independence
  ✗ Parent dictates all subsidiary business decisions
  ✗ No separate subsidiary board meetings
  ✗ Subsidiary uses parent's letterhead exclusively
  ✗ Third parties unaware they deal with separate entity
  ✗ Inadequate subsidiary capitalization

MEDIUM RISK: Inadequate Separation
  ⚠ Same officers but separate board meetings
  ⚠ Shared services without proper intercompany agreements
  ⚠ Informal capital contributions ("just put money in")
  ⚠ Centralized treasury without documented terms
  ⚠ Parent guarantees subsidiary debt without consideration

LOW RISK: Proper Separation Maintained
  ✓ Separate bank accounts
  ✓ Subsidiary has own board meetings and minutes
  ✓ Independent officers (can overlap but act independently)
  ✓ Intercompany agreements at arm's length
  ✓ Subsidiary adequately capitalized for its business
  ✓ Third parties clearly informed of separate entity
  ✓ Contracts in subsidiary's name, signed by subsidiary officers
```

### Veil Piercing Litigation Discovery

What creditor attorneys request when pursuing veil piercing:

```
DISCOVERY REQUESTS:
✓ All corporate records (minutes, resolutions, bylaws)
✓ Bank statements (looking for commingling)
✓ Financial statements
✓ Intercompany agreements and transactions
✓ Capitalization records
✓ Contracts and how they were signed
✓ Insurance policies
✓ Tax returns

SMOKING GUNS THEY SEEK:
- Personal purchases on entity accounts
- Entity purchases on personal accounts
- No meeting minutes or resolutions
- Owner signing personally (not as officer)
- Inadequate initial capital
- No formal distributions (owner just takes money)
- Intercompany transactions with no documentation
- Parent treating subsidiary as department
```

## Model Implications

### What the Current Model Tracks (Good)

- Meeting minutes (`meetingMinutes` table)
- Resolutions (`resolutions` table)
- Board composition (`boards`, `directors` tables)
- Officers (`officers` table)
- Shareholders and ownership (`shareholders`, `shareholdings` tables)
- Annual filings (`annualFilings`, `filingRequirements` tables)
- Registered agents (`registeredAgents` table)
- Bylaws (`bylaws` table)
- Parent-subsidiary relationships (`parentSubsidiaryRelationships` table)

### What the Current Model Does NOT Capture (Gaps)

```
1. FINANCIAL SEPARATION TRACKING
   ✗ No link to bank accounts
   ✗ No capitalization tracking
   ✗ No commingling detection

2. INTERCOMPANY TRANSACTION GOVERNANCE
   ✗ No intercompany agreements table
   ✗ No intercompany loan tracking
   ✗ No transfer pricing documentation
   ✗ No arm's length verification

3. CONTRACT SIGNING FORMALITIES
   ✗ No contract registry showing entity as party
   ✗ No signing authority verification
   ✗ No track of who signed in what capacity

4. VEIL HEALTH SCORING
   ✗ No formality compliance scoring
   ✗ No risk assessment for veil piercing
   ✗ No alerts for missing formalities
```

## Why This Matters

1. **Liability protection** - The entire point of entities is liability shielding
2. **Litigation defense** - Formalities become evidence in veil piercing litigation
3. **Multi-entity structures** - Parent-subsidiary separation is critical
4. **Tax compliance** - Intercompany transactions need transfer pricing support
5. **Audit readiness** - Proper documentation prevents problems
