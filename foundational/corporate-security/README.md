# Corporate Security

Business protection, continuity, and risk management (non-IT security).

## Subdomains

### physical-security
Facility access and protection.
- `facility.ts` - Physical locations
- `access-zone.ts` - Security zones/areas
- `access-badge.ts` - Badge/credential management
- `access-log.ts` - Entry/exit records
- `visitor.ts` - Visitor management
- `surveillance-system.ts` - Camera and monitoring systems

### personnel-security
Employee security vetting.
- `background-check.ts` - Pre-employment screening
- `security-clearance.ts` - Clearance records
- `clearance-level.ts` - Confidential, secret, top secret
- `periodic-reinvestigation.ts` - Clearance renewals
- `adverse-information.ts` - Derogatory information

### information-classification
Data and document classification.
- `classification-level.ts` - Public, internal, confidential, restricted
- `data-classification.ts` - Classified data records
- `handling-procedure.ts` - Classification-specific procedures
- `marking-requirement.ts` - Labeling requirements
- `declassification.ts` - Downgrade procedures

### business-continuity
Crisis management and recovery.
- `bcp.ts` - Business Continuity Plan
- `crisis.ts` - Crisis/incident records
- `crisis-response.ts` - Response activities
- `recovery-objective.ts` - RTO/RPO definitions
- `alternate-site.ts` - Backup facility information
- `bcp-test.ts` - Plan testing and exercises

### fraud-prevention
Internal controls and fraud detection.
- `internal-control.ts` - Control definitions
- `segregation-of-duties.ts` - SoD matrix
- `fraud-risk.ts` - Fraud risk assessments
- `fraud-indicator.ts` - Red flag indicators
- `fraud-investigation.ts` - Investigation records

### vendor-security
Third-party security assessment.
- `vendor-risk-assessment.ts` - Vendor risk evaluations
- `security-questionnaire.ts` - Assessment questionnaires
- `vendor-risk-rating.ts` - Risk classifications
- `security-review.ts` - Periodic review records
- `vendor-remediation.ts` - Required improvements

### incident-response
Security incident management.
- `security-incident.ts` - Incident records
- `incident-severity.ts` - Severity classifications
- `incident-response-plan.ts` - Response procedures
- `breach-notification.ts` - Required notifications
- `lessons-learned.ts` - Post-incident analysis

### security-governance
Security program management.
- `security-policy.ts` - Security policies
- `risk-assessment.ts` - Security risk assessments
- `security-metric.ts` - Security KPIs
- `security-committee.ts` - Governance structure
- `security-roadmap.ts` - Improvement initiatives

## Key Integrations

- **compliance**: Control testing, audit support
- **entity-governance**: Personnel records
- **data-privacy**: Incident coordination
- **contracts-legal**: Vendor security requirements
